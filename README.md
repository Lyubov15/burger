# Boom Burger 

Одностраничный сайт ресторана, который знакомит посетителя с заведением, помогает изучить меню и преимущества, посмотреть отзывы и акции, а затем перейти к бронированию столика.

**[Открыть сайт](https://lyubov15.github.io/burger/)**

## Пользовательский сценарий

Посетитель попадает на яркую главную страницу с акцентом на фирменный бургер и предложение ресторана. Далее он может перейти к меню, узнать об особенностях заведения, ознакомиться с отзывами и действующими акциями. Основные разделы связаны навигацией и ведут к форме бронирования.

## Что реализовано

- **Промо-блок ресторана** с акцентным предложением, изображением блюда и призывом забронировать стол.
- **Навигация по разделам** с отдельным мобильным меню.
- **Меню бургеров** с категориями и слайдером позиций.
- **Блок преимуществ** с информацией о продуктах, открытой кухне и атмосфере ресторана.
- **Слайдер отзывов** для представления мнений посетителей.
- **Раздел акций** с таймером обратного отсчёта.
- **Форма бронирования** с проверкой введённых данных, маской номера телефона и отправкой формы через AJAX.
- **Анимации появления элементов** при прокрутке страницы.
- **Адаптивная вёрстка** для настольных компьютеров, планшетов и смартфонов.

## Технологии

| Технология | Использование |
|---|---|
| HTML5 | Структура и семантическая разметка страниц |
| SCSS / Sass | Организация и компиляция стилей |
| JavaScript / jQuery | Интерактивность и обработка действий пользователя |
| Gulp | Автоматизация сборки стилей |
| Slick Slider | Слайдеры меню и отзывов |
| WOW.js, Animate.css | Анимации при прокрутке |
| jQuery Inputmask | Маска ввода номера телефона |
| jQuery UI | Интерактивные элементы интерфейса |

## Запуск проекта

Требуется Node.js и npm.

```bash
git clone https://github.com/Lyubov15/burger.git
cd burger
npm install
```

Для автоматической компиляции SCSS при изменении файлов:

```bash
npx gulp watch
```

Для однократной сборки стилей:

```bash
npx gulp sass
```

После сборки откройте `index.html` в браузере.
