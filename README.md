# Boom Burger

Адаптивный лендинг ресторана бургеров **Boom Burger** (г. Москва).

Проект представляет собой современный одностраничный сайт с анимациями, интерактивными слайдерами, таймером акции и формой бронирования стола. Лендинг полностью адаптирован для корректного отображения на компьютерах, планшетах и мобильных устройствах.

## Возможности

- 📱 Адаптивная вёрстка для всех типов устройств;
- 🍔 Мобильное бургер-меню;
- 🎞️ Слайдер меню;
- 💬 Слайдер отзывов;
- ✨ Анимации появления элементов при прокрутке страницы;
- ⏳ Таймер обратного отсчёта акции;
- 📅 Форма бронирования стола;
- ✔️ Валидация формы;
- 📞 Маска ввода номера телефона;
- 📤 Отправка данных формы через AJAX.

## Используемые технологии

## Установка и запуск

### 1. Клонирование репозитория

```bash
git clone https://github.com/Lyubov15/burger.git
cd burger
```

### 2. Установка зависимостей

```bash
npm install
```

### 3. Запуск режима разработки

Автоматическая компиляция SCSS при изменении файлов:

```bash
npx gulp watch
```

### 4. Сборка стилей

Однократная компиляция SCSS:

```bash
npx gulp sass
```

### 5. Запуск проекта

После сборки откройте файл **index.html** в любом современном браузере.
